Data description
-------------------------------------------------
A network representing the foodweb of the Sanak Archipelago in Alaska. The network is related to the foodweb of the Sanak Intertidal (note that the article also discusses the nearhore ecosystem). The network is directed. Nodes represent species (taxa) or some other organic component and there is an edge A -> B if A eats (consumes) B.
